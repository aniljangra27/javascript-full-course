# JavaScript Full Course

This project is a comprehensive JavaScript learning resource, covering concepts from basic to advanced. It includes code examples, exercises, and explanations to help you master JavaScript.

## Project Structure

- `arrays.js` - Examples and operations on JavaScript arrays
- `arrow-function.js` - Usage of arrow functions and function chaining
- `script.js` - DOM manipulation and basic operations
- `index.html` - Main HTML file to run scripts in the browser
- `fundamental/index.js` - Template literals, array methods, and practice problems

## How to Use

1. Clone or download this repository.
2. Open `index.html` in your browser to see the output of scripts.
3. Run individual JavaScript files using Node.js:
   ```sh
   node arrays.js
   node arrow-function.js
   node script.js
   ```
4. Edit and experiment with the code to deepen your understanding.

## Topics Covered

- Variables and Data Types
- Arrays and Array Methods
- Functions and Arrow Functions
- Template Literals
- DOM Manipulation
- Sorting and Iteration
- Practice Problems
